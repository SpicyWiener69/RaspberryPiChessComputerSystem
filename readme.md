### Chess Computer System based on a Raspberry Pi

## Folder Descriptions
```
.
├── UI/:    Chess UI frontend. Allows players to adjust game settings.
├── core/:  program entry point. Handles game logic.
├── ChessBoardPCB/: A PCB board with hall effect sensors designed to sense the position of a chess game. Designed in Kicad7.
└── hardware/: BOM, 3d design files of the system. Designed in Fusion360.
```
More info is written at every subfolder's readme.md file.
